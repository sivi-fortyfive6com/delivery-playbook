# RACI Matrix

**R** Responsible (does the work) · **A** Accountable (one person signs off) · **C** Consulted · **I** Informed

| Activity | Sponsor | Programme lead | Product owner | Delivery team | Architecture | Risk/Compliance |
|---|---|---|---|---|---|---|
| Business case | A | R | C | I | C | C |
| Scope & prioritisation | C | C | A/R | C | C | I |
| Solution design | I | C | C | R | A | C |
| Build & test | I | A | C | R | C | I |
| Go-live decision | A | R | C | C | C | C |
| Benefits tracking | A | R | C | I | I | I |

**Rules:** exactly one **A** per row. If a row has no **R**, nobody is doing the work.
