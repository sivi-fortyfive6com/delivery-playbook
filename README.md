# Delivery Playbook

Practical, reusable templates for running programmes and product delivery. I've refined them over 27+ years in banking, payments, agriculture and retail. Copy them, adapt them and use them.

| Template | Use it when… |
|---|---|
| [Stage gates](templates/stage-gates.md) | You need clear go/no-go decisions across a programme |
| [MoSCoW prioritisation](templates/moscow-prioritisation.md) | Too many requirements and not enough capacity |
| [PASO executive summary](templates/paso-executive-summary.md) | You have one page to win an executive decision |
| [RACI matrix](templates/raci.md) | Nobody is sure who decides what |
| [Kanban → Scrum transition](templates/kanban-to-scrum.md) | A team is ready to move from flow to sprints |

## Principles

1. **Outcomes over output.** Every plan starts from the business result.
2. **Make work visible.** If it isn't on the board, it isn't happening.
3. **Pilot, prove, then scale.**
4. **Write for the reader.** Executives need decisions, teams need clarity.
5. **Tools follow the operating model**, not the other way round.
